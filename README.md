# Mi Closet

Sitio personal para organizar la ropa por secciones, con cajas que tienen su propio código QR.

- Página: GitHub Pages (`index.html`)
- Datos y fotos: Supabase (`supabase-setup.sql` crea las tablas, permisos y el bucket de fotos)
- Configuración: `config.js` (Project URL y anon key; nunca la service_role)
